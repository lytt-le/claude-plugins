# caterpillar-pet

A tiny green caterpillar that inches back and forth along the band above the Claude Code prompt, the way a real inchworm moves: it arches its back to pull its rear end in, then rolls the hump forward and flattens out as its front end reaches ahead. It turns around at each edge.

```
▄▄▄▄▄▄▄▄   →   ▄▞▀▀▚▄   →   ▄▄▄▞▀▚▄   →   ▄▄▄▄▄▄▄▄
```

It sits on its own row, so it gets along fine with other pets such as clawd-pet. Collapse the band with ctrl+x ctrl+a.

## Install

```
claude plugin install caterpillar-pet --marketplace lytt-le/claude-plugins
```
